## Core equation

MEM|8 wave encoding:

```
M_xyz(t) = A_xyz(e,t) · e^(i(ωt + φ_xyz)) · D(t,τ) · I(x,y,z,N)
```

- **A** amplitude (strength) · **ω** frequency · **φ** phase · **D** decay · **τ** time constant · **I** interference
- **τ = ∞** — never forget (precious memories). Routine context fades.
