Every [curated Reader](/explorer/?edition=curated) links to its preserved source,
PDF where available, and full Reader Markdown. The illustration page provides
the original image and its text transcription.

- [Download the complete repository as ZIP](https://github.com/8b-is/8b-public-documents/archive/refs/heads/main.zip) for the curated sources, existing documents, and the site build.
- [Curated document catalog (JSON)](/library/catalog.json) includes authorship, editions, source hashes, topics, and relationships.
- [Existing collection catalog (JSON)](/collection-catalog.json) lists legacy web documents and PDF editions.
- [Compression trial and reproducible script](https://github.com/8b-is/8b-public-documents/tree/main/library-tools) explains which transformations preserved the tested inputs and which changed them.

A downloaded copy retains the work’s original attribution and reuse terms.
For a smaller selection, download individual files from their Reader pages.
